# Planit

Planit 是一款以**依赖驱动排期**为核心的浏览器端项目排期工具。
改任何一个任务、依赖、日历或资源，整份计划立即自动重排；关键路径实时高亮；
资源超载自动平衡；所有操作均可撤销。一切都在浏览器内运行与保存 ——
无需服务端，无需注册。

## 亮点

- **自动重排** —— 改动任何任务、依赖、日历或资源，整份计划立即重算
- **实时关键路径** —— 零浮时链路始终在甘特图上一眼可辨
- **资源平衡** —— 超载资源会借助任务浮时自动错开
- **为大规模而生** —— 虚拟化渲染 + 主线程外求解，万级任务计划依旧流畅
- **一份计划，四种视图** —— 甘特 / 大纲 / 日历 / 资源，外加任务与项目检查器
- **完整撤销 / 重做** —— 拖拽一次记一步，绝不退半步
- **本地优先** —— 数据自动存于浏览器，无需服务端、无需注册
- **三语界面** —— 中文 / English / 日本語，随时切换

## 功能详解

### 任务与排期

- **任务树** —— 摘要任务、子任务与里程碑统一在一棵树里；摘要日期自底向上自动汇总，
  任务类型（叶子 / 分组）由结构自动推导，不会出现不一致数据。
- **两种排期方式**
  - **自动** —— 由依赖与约束求解；每个任务可挂成对的开始 / 结束约束
    （不早于 / 不晚于）。
  - **手动** —— 区间钉死，不被依赖或平衡移动；与手动任务相撞的依赖会作为冲突提示，
    而不是被悄悄吸收。
- **ASAP / ALAP** —— 每个任务可在其可行窗口内选择尽早或尽晚；项目整体可正向
  （从起点）或逆向（从截止日）排期。
- **拖拽排期** —— 拖动任务条平移，拉两端把手改开始日或工期；落点自动吸附到工作日，
  拖拽落下的任务转为手动排期。
- **里程碑** —— 零工期的时间点，可挂依赖、可被平衡推迟。

### 依赖

- **四种依赖类型** —— 完成→开始、开始→开始、完成→完成、开始→完成，
  甘特图上从任务条端点直接拖出即可建立。
- **延迟（lag）三种单位** —— 工作日、自然日（跨周末与节假日）、前置任务工期的百分比；
  均可为负（提前量）。
- 依赖成环在建立时即被拒绝。
- 无法满足的依赖会列入冲突清单，而不是被静默调和。

### 自动排期与关键路径

- 完整的**关键路径法（CPM）**求解：正推（最早日期）、逆推（最晚日期）、
  总浮时与自由浮时。
- **改任何一处，全盘重算** —— 工期、依赖、约束、日历、分配，任一变化都触发重求解。
- **实时关键路径** —— 零浮时链路在甘特图上高亮。
- 冲突集中在专门的清单里，必要时给出偏差多少个工作日。
- 求解跑在 Web Worker 上，万级任务计划在重算期间界面依然流畅；大纲与甘特均采用虚拟滚动渲染。

### 工作日历

- 每个项目自带**可配置的工作日历** —— 周工作日勾选，加上任意日期的节假日例外。
- 例外可按**单日或区间**增删，区间作为一步整体撤销。
- **月度日历视图**对工作日 / 非工作日 / 例外日三态着色，点选日期即可切换。
- 资源可挂**独立日历**，也可沿用项目默认日历。
- 改日历立即全盘重算。

### 资源与工作量

- **四种资源类型** —— 人员、设备、材料、分组（分组可嵌套）。
- 每项资源可配：**可用率**（如半职 50%）、**效率**、**可用期间**（入职日 / 租期）、
  **成本**（每次使用 + 每小时费率）。
- **分配有两个对称入口** —— 任务面板的「这个任务用了谁」、资源面板的
  「这个人负责哪些任务」，同一份记录、同一套命令。
- **两种投入模型** —— 固定工期（多派一人增加工作量、工期不变）与固定工作量
  （多派一人真的缩短工期）。
- 每个任务与资源都显示派生总量：使用次数、总时数、总成本。

### 资源平衡

- 当某项资源在某天被排到超负荷时，规划器会**在各自浮时内把任务往后推**，
  直到负载满足或浮时耗尽。
- **优先级决定谁先让位** —— 高优先级任务先占用资源，被钉死的任务
  （手动排期 / 约束）绝不移动。
- 无法消除的超载会被精确报告：哪项资源、哪一天、负载多少。
- 资源视图的时间线**高亮超载**，一眼看出谁在哪天被排爆。
- 平衡只是一条普通命令，可以撤销。

### 基线与挣值

- **多基线快照** —— 随时抓取整份计划的快照，可存多份，自由切换对比基线。
- **排期差异** —— 每个任务以工作日显示其基线开始 / 结束与当前排期之差。
- **挣值** —— BAC、EV、PV、SV 均由成本与进度派生。
- 设置基准日（status date）并选定活动基线，即可计算 PV 与 SV。

### 视图

- **甘特视图** —— 任务条、依赖连线（四种类型的端点语义正确）、关键路径高亮、
  非工作日底纹、拖拽排期。
- **大纲视图** —— 表格化的任务树，列集可配置（开始、结束、浮时、已分配、成本、
  差异……），列宽可拖拽调整，偏好持久化。
- **日历视图**与**资源视图**共同组成四段式视图切换器。
- **双 Tab 检查器**（任务 / 项目）汇聚任务信息、排期、约束、依赖、分配、基线与挣值。

### 数据、撤销与多语言

- **命令模型** —— 所有数据变更都经过注册命令；UI 只负责派发，绝不直接写数据。
- **完整撤销 / 重做** —— 自动生成正向与逆向补丁，拖拽一次即一条撤销记录。
- **自动存盘** —— 防抖写入浏览器存储，刷新不丢；随着 schema 演进，旧存档始终可打开。
- **三语界面** —— 中文 / English / 日本語，所有文案（含撤销提示）均完整翻译。
